Software Architecture

Model-View-Controller & Domain-Driven Design

The system enforces strict separation of concerns, pairing server-rendered EJS interfaces with robust RESTful JSON APIs and PostgreSQL storage.

🏛️

MVC Pattern Separation

Autonomous models encapsulate SQL and validation logic, web controllers render EJS templates, while API controllers deliver OpenAPI-compliant JSON payloads.

🔗

N:M Action Table (Applications)

Graduates and career opportunities are bridged through the verified applications action table, with complete candidate tracking and unique constraints.

🛡️

Guardians & Observability

404 Guardian, 5xx Guardian (logs/error.logs), and real-time terminal logger capture metrics across every HTTP request.

Technical Foundation

Built on Modern Web Technologies

⚡

Node.js 20 & Express 5

High-performance async server handling multipart form parsing, JSON schemas, and routing.

🐘

PostgreSQL 16 & Fallback

Relational database with Docker named volumes, with automated in-memory store fallback for seamless testing.

🐳

Docker Compose & Forgetting Test

Containerized orchestration tested against container teardowns to prove persistent graduate data retention.

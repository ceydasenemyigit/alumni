Course Project

About This Project

The Alumni Tracking System is an academic web application developed for the Web Programming course at Istanbul University. It provides comprehensive alumni management, career tracking, and university networking services through RESTful API endpoints.

Tech Stack

Runtime & Server

Node.js & Express.js with REST API architecture

API Documentation

Interactive Swagger UI & OpenAPI 3.0 specification

Data Persistence

In-Memory Store (transitioning to PostgreSQL database)

DevOps & Tooling

Docker, Docker Compose & automated test suite

Key Capabilities

The platform supports user registration via Form URL-Encoded, JSON, and multipart formats, complete CRUD operations, granular field patching, and system diagnostics with real-time health checks.
